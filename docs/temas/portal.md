## Resumen

Presenta el MCP remoto de Mercado Libre para buscar documentación y recuperar páginas desde clientes compatibles como Claude, Codex, Cursor, Windsurf y otros IDEs. El cliente inicia autenticación OAuth 2.0.

## Contenido y conceptos documentados

- La configuración publicada apunta a `https://mcp.mercadolibre.com/devsite/v1/mcp`; se muestran ejemplos JSON/TOML por cliente. El MCP no funciona con credenciales de usuario TEST.
- Herramientas: `search_documentation` requiere `query` y `language`, admite `siteId`, `limit` y `offset`; `get_documentation_page` requiere `path`.
- La página incluye pasos de conexión y diagnóstico de errores OAuth, sesión y URL. Es una interfaz MCP remota; no documenta una operación REST de la API pública: No documentado en la fuente.
